# Шифр Цезаря

Консольная программа для шифрования и дешифрования текста по алгоритму
Цезаря. Поддерживает русский и английский алфавиты, сохраняет регистр,
не изменяет цифры и знаки препинания.

## Запуск

​```bash
python caesar_cipher.py
​```

## Использование

Программа запросит по очереди:

1. Предложение для шифрования/дешифрования
2. Сдвиг - целое число ≥ 0
3. Направление: `ш` (шифрование) или `д` (дешифрование)
4. Язык: `Ru` или `Eng`

### Пример

​```
Введите предложение: Умом Россию не понять
Введите сдвиг: 1
Шифрование или дешифрование (ш/д)? ш
Выберите язык (Ru/Eng): Ru
Фнпн Спттйя ож рпоауэ
​```

## Ограничения

- Буква "ё" не поддерживается - используйте "е"
- Смешивание русского и английского в одном тексте не допускается
