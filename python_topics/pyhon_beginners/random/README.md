# Mini-project - *Random module*
## Description

> Модуль random предоставляет функции для генерации случайных чисел, букв и случайного выбора элементов последовательности (списка, строки и т.д.).

Для использования этих функций в начале программы необходимо подключить модуль, что делается командой import:

```Python
import random
```


После подключения модуля мы можем использовать его функции.

Числа, генерируемые с модулем Random - псевдослучайные и зависят от системного времени из внутреннего генератора тактовых импульсов компьютера, использует его как начальное значение. Системное время - целое число, представляющее текущую дату и время вплоть до одной сотой секунды.

Вместе с тем, могут иметься некоторые программы, где требуется всегда генерировать одну и ту же последовательность случайных чисел. При необходимости для этого можно вызвать функцию *seed()*, задав начальное значение.




## Functions

> **random()**

Возвращает случайное число с плавающей точкой в диапазоне от 
0.0 до 1.0 (исключая 1.0).

> **random.uniform(a, b)**  

Возвращает псевдослучайное число с плавающей   запятой в      диапазоне от a до b включительно. 

> **random.randint(a, b)**                        

Возвращает псевдослучайное целое число в диапазоне [a, b).


> **random.choice(a)**                          

Возвращает псевдослучайный элемент из любой последовательности. Функция choice() принимает список (строку) в качестве обязательного аргумента и возвращает один случайный элемент из переданного списка (строки).



> **random.randrange(a, b, c)**                 

Возвращает псевдослучайное число из диапазона от a до b с шагом c.



> **random.shuffle(a)**                 

Перемешивает список a случайным образом, а затем выводит его содержимое.



> **random.sample(population, k)**                  

Возвращает список длиной k из уникальных элементов, выбранных из последовательности или множества population.
