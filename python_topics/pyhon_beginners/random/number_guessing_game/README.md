# Проект "Угадайка чисел"

**Описание проекта:** 
> «Угадайка чисел» — это консольная игра на Python, в которой пользователь самостоятельно задаёт диапазон возможных чисел, а программа случайным образом загадывает число внутри этого диапазона.
> Задача пользователя — угадать загаданное число за минимальное количество попыток.
> После каждой попытки программа сообщает, больше или меньше введённое число загаданного. Когда пользователь угадывает число, программа поздравляет его и выводит количество использованных попыток.
> После завершения игры пользователь может сыграть ещё раз.
---

**Возможности проекта**
- Пользователь самостоятельно задаёт минимальную и максимальную границы диапазона.
- Программа случайным образом загадывает число в указанном диапазоне.
- Проверяется корректность введённого числа.
- Пользователь получает подсказку:
    - введённое число меньше загаданного;
    - введённое число больше загаданного.
- Ведётся подсчёт количества попыток.
- После окончания игры можно сыграть ещё раз.
- Программа обрабатывает некорректные ответы пользователя.

***Используемые технологии и конструкции Python***

- целые числа (int);
- строки (str);
- переменные;
- функции;
- вложенная функция is_valid();
- пользовательский ввод и вывод данных (input() и print());
- условные конструкции if / elif / else;
- цикл while;
- бесконечный цикл while True;
- операторы break и continue;
- преобразование типов с помощью int();
- проверка строк методом isdigit();
- работа со списками;
- импорт модуля random;
- функция randint() для генерации случайного числа.

**Обработка ошибок**
---

Если пользователь задаёт диапазон, в котором минимальное число больше максимального, программа сообщает об ошибке и предлагает ввести границы заново:
> Выбери минимальное возможное число: 100
> Выбери максимальное возможное число: 1

> Нижняя граница не может быть больше верхней! Давай попробуем еще раз

Также программа проверяет введённую догадку и просит ввести целое число в допустимом диапазоне.
