# Notes

## How Binary Search Works

Бинарный поиск каждый раз делит область поиска примерно пополам.

Например:

`128 → 64 → 32 → 16 → 8 → 4 → 2 → 1`

Поэтому максимальное количество проверок определяется логарифмом по основанию 2:

`log₂(128) = 7`

### Exercise 1.1

**Question:**
Имеется отсортированный список из 128 имен. Мы ищем значение методом бинарного поиска. Какое максимальное количество проверок может потребоваться?

**Answer:**
`7` проверок.

### Exercise 1.2

Если размер списка увеличить вдвое:

`128 → 256`

то:

`log₂(256) = 8`

**Answer:**
Максимальное количество проверок увеличится с `7` до `8`.

### Key takeaway

Увеличение размера списка в два раза добавляет примерно одну проверку, а не удваивает количество проверок.
